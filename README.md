## О проекте

Box создаётся как самостоятельный язык программирования. Его синтаксис и правила задаются автором проекта. Box не является диалектом Python.

Этот репозиторий предназначен для хранения документации, примеров и исходного кода языка.

## Начало программы

Программа Box начинается маркером `#Start#` и завершается `#End#`.

```box
#Start#
P {Привет, мир}!
#End#
```

## Переменные-блоки

В Box данные можно сохранять в именованные блоки.

### Запись значения

Команда `P` с конструкцией `box` записывает значение в блок:

```box
P {123} box {A}!
```

### Создание блока

```box
C box {b}!
```

Команда `C` создаёт блок с именем `b`.

### Просмотр и изменение

- `>` используется для вывода содержимого блока.
- `=` используется для присваивания или изменения значения.
- `D` удаляет блок.

Пример просмотра:

```box
Box {a}>
```

Пример изменения:

```box
Box {a}={новое значение}!
```

Пример удаления:

```box
D box {g}.
```

## Вывод и изменение данных

Команда `P` выводит текст или значение. Если команда содержит `box {имя}`, значение записывается в указанный блок.

```box
#Start#
P {Добро пожаловать в Box}!
P {42} box {Answer}!
#End#
```

## Арифметика

Подтверждённые арифметические операторы:

| Оператор | Действие |
|---|---|
| `+` | Сложение |
| `-` | Вычитание |
| `*` | Умножение |
| `/` | Деление |

Пример:

```box
#Start#
P {123321} box {A}!
P {123321} box {B}!
A+B=246642 box {D}!
#End#
```

В примере значения блоков `A` и `B` складываются, а результат записывается в `D`.

## Условия

Для проверки условия используется `yesli`, а для альтернативной ветви — `Nosli`.

```box
#Start#
P {100} box {A}!
P {100} box {B}!

yesli box {A}==box {B} to P {Числа равны}!
Nosli P {Числа не равны}!

#End#
```

- `yesli` проверяет условие.
- `==` сравнивает значения.
- `to` связывает условие с выполняемой командой.
- `Nosli` задаёт альтернативную ветвь, если условие не выполнено.

**Важно:** `Nosli` и `nosli` — разные записи.

## Циклы

Циклы имеют собственные идентификаторы. Вложенные циклы не допускаются.

| Команда | Назначение |
|---|---|
| `L {Worker}` | Объявляет цикл с идентификатором `Worker` |
| `Start {Worker}!` | Запускает или перезапускает цикл с начала |
| `Stop {Worker}!` | Приостанавливает цикл |
| `End {Worker}!` | Удаляет цикл из памяти и освобождает его идентификатор |

Правила циклов:

- Можно создавать несколько независимых циклов с разными идентификаторами.
- Нельзя объявлять два цикла с одинаковым идентификатором.
- Нельзя вкладывать один цикл в другой.
- После `Stop` команда `Start` начинает цикл заново.
- После `End` идентификатор можно использовать повторно.
- Обращение к неизвестному идентификатору цикла должно вызывать ошибку.

Полная форма записи тела цикла будет уточняться по мере разработки интерпретатора.

## Другие команды

| Команда | Назначение |
|---|---|
| `U` | Команда пользовательского ввода |
| `W(3)` | Ожидание 3 секунды |
| `stop` | Останавливает ближайший цикл |

Точные параметры и варианты использования будут документироваться после окончательного утверждения.

## Регистр символов

Имена команд чувствительны к регистру. Например, `Nosli` и `nosli` не считаются одной и той же записью.

## Ошибки

Уже определённые сообщения:

| Ситуация | Сообщение |
|---|---|
| Отсутствует `#Start#` | `Err start not found` |
| `#Start#` указан повторно | `Error start` |
| Отсутствует `#End#` | `end not found` |

Также должны обрабатываться ошибки циклов: неизвестный идентификатор и повторное объявление существующего идентификатора.
